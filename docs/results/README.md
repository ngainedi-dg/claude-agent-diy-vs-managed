# Results (metrics only)

Per-run numbers from the experiment described in [../comparison.md](../comparison.md). Generated by `uv run python -m experiments.export_results` from the local, gitignored `results/` directory.

| File | Contents |
|---|---|
| `experiment-1.json` | 10 runs (5 DIY, 5 Managed): status, time, calls, tokens, cost, artifact and schema checks, anomaly detection by ID, numeric-claim counts; plus the aggregate used in the report |
| `experiment-1.md` | the same as readable tables |
| `failure-scenarios.json` | the seven fault scenarios: status, expected answer, calls, time, cost |
| `failure-scenarios.md` | the same as readable tables |

**Included:** numbers, booleans, statuses, anomaly IDs (A01-A11, L01-L03), and the one-word answers the fault tasks asked for.

**Not included:** anything the agents wrote (reports, findings, final messages, tool inputs and outputs, traces), session, agent and file IDs, timestamps, and local paths. The exporter copies from an explicit allowlist of fields, and a test checks that planted text and IDs do not get through.

How to read them: `unavailable` or `null` means a value could not be observed, not zero. Costs are our estimate from token counts with one price table for both sides, plus the Managed runtime charge; the platform's own reported cost is in `reported_list_cost_usd`. Five runs per side is a small sample.
